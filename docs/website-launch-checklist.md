# Website Launch Checklist

- [x] Remove the noindex tag.
- [x] Set up Google Search Console.
- [x] Submit the sitemap in Google Search Console.
- [x] Request indexing for the homepage.
- [x] Set up Bing Webmaster Tools.
- [x] Install Google Analytics.
- [x] Create a Google Business Profile (formerly Google My Business).
- [x] Switch the website to HTTPS.
- [x] Test the website on mobile devices.
- [x] Make sure all page titles are unique.
- [x] Add a favicon to the website.
- [x] Set the brand name as the website site name.
- [x] Redirect all old URLs with 301 redirects.
- [x] Check website page speed.
- [x] Log all search verification codes in an approved secure location; do not commit codes to the repository.
